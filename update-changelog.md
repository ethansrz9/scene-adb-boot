# Scene ADB Boot Activator v2.0

- Added KernelSU/SukiSU automatic update metadata through `updateJson`.
- Added a formal GitHub Release asset for module-manager downloads.
- Preserved the v1.9 runtime script contents and restored their executable permissions.
- Boot activation does not open Scene; manual activation closes the action page and then opens Scene.
- Preserved Android shell UID 2000 execution for ADB-mode behavior.
- The installed module has no runtime dependency on Sui.
